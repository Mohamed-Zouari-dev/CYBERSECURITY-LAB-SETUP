# NETWORKWALKS-MOHAMED-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP
 built a virtual cybersecurity lab on Windows 11 using VirtualBox and Kali Linux 2026.2. Kali runs on a private NAT Network with a static IP, so I can safely practice scanning, reconnaissance, and exploitation, and later add vulnerable target machines. The setup includes updates, connectivity checks, clean snapshot, and documented troubleshooting.
